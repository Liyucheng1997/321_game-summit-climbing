# 巅峰攀登 · Summit Climb

一款基于 Three.js 的 3D 登山模拟游戏：程序生成的高山、以真实坡度驱动的行走 / 攀爬 / 滑坠物理、体力与体温系统、风雪天气、落石、营地与补给。四种难度可选。

## 运行方式

- 直接双击 `index.html` 即可（所有依赖都已本地化，无需联网、无需安装）。
- 或者在本目录启动任意静态服务器，例如：

```bash
python -m http.server 8765
```

然后打开 http://localhost:8765 。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 移动（缓坡行走，陡坡自动攀爬） |
| 鼠标拖拽 / 点击锁定 | 旋转视角；滚轮缩放 |
| Shift | 冲刺（仅缓坡，消耗体力） |
| 空格 | 缓坡跳跃；攀爬时向上猛冲（−12 体力）；滑坠时按住制动 |
| Tab（按住） | 拉远俯瞰，规划路线 |
| R | 回到上一营地（+20 秒） |
| Esc | 暂停 / 查看规则 |
| M | 静音 |

## 玩法要点

- **坡度决定一切**：≤42° 可以行走并恢复体力；42° 到约 75° 进入攀爬状态，越陡、雪面越滑、逆风越强，体力消耗越快；静止在 64° 以下可以慢慢回复体力。
- **体力耗尽会脱手滑坠**，按住空格自我制动。岩石面容易停住，雪面稍差，冰面几乎停不住。速度过快撞击会受伤，摔落高度过高会受伤甚至遇难。
- **体温**在高海拔、强风、暴风雪中持续流失，为 0 后生命持续下降。营地可快速回温、回血并保存复活点，补给箱恢复体力 / 体温 / 生命。
- **暴风雪**来临前会有预警，期间视野极差、风力翻倍。**落石**会从上方陡壁滚下并砸伤玩家。
- **路线规划**是核心：不要硬冲直线，寻找台阶状岩架、缓坡与营地，分段攀登。
- 结算按用时、滑坠次数、伤害、补给收集与难度倍率计算得分并评级（S / A / B / C）。

## 难度

| 难度 | 峰高 | 营地 | 天气 | 落石 | 生命 |
| --- | --- | --- | --- | --- | --- |
| 简单 | 约 240 m | 4 | 温和 | 无 | 无限 |
| 普通 | 约 340 m | 3 | 偶发暴风雪 | 少 | 无限 |
| 困难 | 约 440 m | 2 | 频繁暴风雪 + 冰面 | 中 | 5 |
| 极限 | 约 540 m | 1 | 狂风暴雪 + 冰面 | 多 | 3 |

菜单中可以输入地形种子复现同一座山，也可以在“画质”中选择低 / 中 / 高以适配不同显卡。

## 代码结构

```
index.html        页面与 HUD / 菜单
css/style.css     界面样式
js/lib/three.min.js  Three.js r152（本地）
js/noise.js       Simplex 噪声与随机数
js/terrain.js     山体高度场生成、采样、着色与网格
js/climber.js     登山者关节模型与程序动画
js/player.js      行走 / 攀爬 / 滑坠 / 空中物理与生存状态
js/world.js       天空、光照、植被、营地、补给、雪花、天气、落石
js/audio.js       Web Audio 合成音效（风、脚步、撞击等）
js/game.js        难度配置、输入、相机、HUD 与游戏流程
```
