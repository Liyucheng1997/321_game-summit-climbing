# 巅峰攀登 · Summit

一款基于 Three.js 的 3D 登山冒险游戏：**爬山、攀岩、露营**三种玩法交织在三座程序生成的山峰上。沿着父亲二十年前留下的登山日志，从湖畔松林一路攀上云海之上的死亡地带。

- 纯前端实现，零外部资源：所有模型、贴图、音效和配乐都是运行时程序生成的
- 浏览器直接运行；也附带 Electron 外壳，可打包为桌面版并接入 Steam 成就

## 运行

- 在线试玩：https://liyucheng1997.github.io/summit-climb/ （需要重新部署本版本后才会更新）

```bash
# 任意静态服务器即可
python3 -m http.server 8765
# 打开 http://localhost:8765
```

也可以直接双击 `index.html`（依赖均已本地化）。

### 桌面版 / Steam

```bash
npm install          # 安装 electron、electron-builder（steamworks.js 为可选依赖）
npm start            # 全屏启动桌面版（npm run start:windowed 为窗口模式）
npm run dist         # 打包 Windows 版到 dist/
```

- `electron/main.js` 为主进程，`electron/preload.js` 通过 `window.steamBridge` 向游戏暴露「解锁成就 / 退出 / 全屏」接口。
- 安装 `steamworks.js` 后自动启用 Steam 覆盖层与成就；游戏内成就 ID（如 `first_wall`）会以大写形式（`FIRST_WALL`）上报，需在 Steamworks 后台创建同名成就。
- `steam_appid.txt` 默认是 Steam 的测试 AppID `480`，上架前替换为你自己的 AppID。

## 玩法

### 三章远征

| 章节 | 山峰 | 特色 |
| --- | --- | --- |
| 第一章 | 青岚山 | 湖畔登山口、松林花海、之字形步道、入门岩壁、第一个夜晚 |
| 第二章 | 鹰嘴岩 | 金色秋林、4 面花岗岩巨壁（悬垂、松动岩块、需要跳跃抓点的路线）、落石、盘旋的老鹰 |
| 第三章 | 霜冠峰 | 冰川与冰裂缝（梯子桥）、冰壁、暴风雪、云海、极光、死亡地带缺氧 |

完成一章解锁下一章。每章三颗星：**登顶**、**收集全部日志并拍下所有观景点**、**标准用时内无死亡登顶**。另有「自由攀登」模式：输入任意种子生成一座全新的山。

### ⛰ 爬山
- 程序生成的山体上用 A\* 规划出带转弯约束的**之字形步道**，沿途有红白路标（夜里会发光）、石堆、固定绳路段。
- 坡度 ≤ 42° 可行走（步道台阶上可达 55°），更陡时手脚并用攀爬并持续消耗体力；过陡或体力耗尽会**滑坠**，按住空格用冰镐制动。
- 冰面几乎无法制动；冰裂缝要走梯子桥，或者助跑跳过去。

### 🧗 攀岩
- 岩壁是危险但快速的捷径。按 **E** 抓住岩点，**WASD** 向对应方向寻找够得着的岩点移动，手脚通过 IK 落在真实的岩点上。
- 岩点类型：**大把手**（可休息回体力）、**小岩点**、**斜面点**（久抓会打滑）、**松动岩块**（抓住 1.6 秒后碎裂）、**冰镐点**。
- **Q** 打岩钉，坠落时绳索在最后一颗岩钉处拉住你，可以悬挂休息、重新抓岩或放绳下降。
- 够不着时**按住空格蓄力**，在绿色区域松开完成跳跃抓点（Dyno）。
- 爬到顶端继续按 W 翻越；也可以在岩壁顶端按 E 向下攀爬。**镁粉**让握力消耗减半。

### ⛺ 露营
- 固定营地和你用 **T** 在任意平地搭起的帐篷都能打开营地菜单：**生火、煮面、续热茶、包扎、睡觉（快进到天亮并存档）、仰望星空**。
- 完整的昼夜循环：日出日落、星空银河、月亮、极光；夜晚寒冷，需要头灯（**L**）照明。

### ❤ 体力与状态
一条体力条统一表现所有生存压力：**饥饿、寒冷、伤势、疲惫、缺氧**会从右侧压缩最大体力，占满整条就会倒下。
能量棒、热茶、绷带、镁粉、氧气瓶可以在快捷栏（1–5）使用；补给包、柴火、岩钉可以在山上找到。

### 其他
- **拍照模式（F）**：冻结时间自由取景、变焦、4 种滤镜，照片存入相册；在观景点拍照完成目标。
- **地图（M）**：手绘风格等高线地形图，显示步道、营地、岩壁、冰裂缝与已发现的收集品。
- **20 个成就**、15 页日志组成的完整故事、中途存档（在营地睡觉时自动保存，主菜单「继续远征」）。
- 支持手柄（左摇杆移动、右摇杆视角、A 跳跃、B 互动、X 岩钉、Y 拍照、Start 暂停）。
- 设置：四档画质（低档关闭后期处理，适合集显）、阴影、视野、灵敏度、反转 Y 轴、主音量/音乐/音效、全屏。

## 技术要点

- **地形**：Simplex 分形噪声 + 山脊噪声 + 台地化的高度场；坡度限制、湖泊雕刻；带转向约束的方向感知 A\* 生成步道，再雕刻出平整的路基。
- **岩壁**：在高度场上雕刻出台地，用独立的起伏岩面网格（含悬垂与圆润顶边）覆盖，保证岩点连通性的路线生成。
- **渲染**：四层可混合地表材质（草地/岩石/雪/泥土，三平面映射 + 高度混合 + 导数凹凸），实例化森林与随风摆动的草地，湖面菲涅尔反射，程序天空（大气渐变、星空、银河、月亮），云海与极光着色器。
- **后期处理**：HDR 渲染目标 → 双级泛光 → ACES 色调映射、调色、暗角、胶片颗粒，并随寒冷/受伤/缺氧/低体力改变画面。
- **角色**：分层关节模型、程序动画与双骨 IK。
- **音频**：Web Audio 合成的风声、脚步、营火、鸟鸣与虫鸣，以及随场景切换情绪的生成式配乐。

## 代码结构

```
index.html          页面结构：HUD、菜单、营地、地图、拍照、结算
css/style.css       界面样式
js/lib/three.min.js Three.js r152（本地）
js/noise.js         Simplex 噪声与可复现随机数
js/util.js          数学工具、几何合并、二叉堆
js/data.js          章节、难度、物品、成就、日志与剧情文本
js/textures.js      程序化无缝贴图（草/岩/雪/土、水面法线、云、火焰）
js/post.js          后期处理管线
js/sky.js           天空、昼夜、星空、月亮、云、云海、极光
js/terrain.js       高度场、步道 A*、岩壁/冰裂缝雕刻、收集品布置、地表着色器
js/walls.js         攀岩墙网格、岩点生成与查询
js/models.js        程序化模型：树木、岩石、帐篷、营火、路标、收集品、桥、飞鸟
js/weather.js       时钟、风雪天气、落石
js/world.js         场景搭建：光照、远景、湖泊、植被、草地、营地、粒子与动画
js/climber.js       登山者模型、程序动画与 IK
js/player.js        玩家物理（行走/攀爬/滑坠/攀岩/绳索）、负面状态与物品
js/audio.js         音效与生成式配乐
js/save.js          存档、成就与相册
js/ui.js            HUD、菜单、地图绘制
js/game.js          主流程：输入、相机、互动、营地、拍照、结算
electron/           桌面版（Steam）外壳
```
